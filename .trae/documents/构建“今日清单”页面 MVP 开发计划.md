收到，根据您的明确反馈，我们将方案调整为**“全屏手帐 + 事后补录”**模式。

## 1. 项目初始化
- [ ] **创建项目**: 使用 Vite 初始化 React + TypeScript 项目。
- [ ] **样式系统**: 安装 TailwindCSS。
  - **核心设计目标**: 还原 A4 纸张手帐体验。
  - **背景**: 设置全屏米色背景，中间放置一个固定比例（类似 A4 纸）的白色容器，带有阴影。

## 2. 核心数据结构 (针对“补录”优化)
- [ ] **数据模型 (Task)**:
  - `title`: 任务名称
  - `category`: 分类（个人/工作/家庭）
  - `estimatedTime`: 预估用时 (小时)
  - `actualTime`: **实际用时** (小时) —— *这是本次的核心字段，用于手动录入*
  - `completed`: 是否完成
  - `level`: 优先级 (Main/Medium/Small)
- [ ] **数据持久化**: 使用 `localStorage` 存储当日数据。

## 3. 页面开发 (New Tab 完整手帐页)
- [ ] **Header 区域**:
  - 显示“个人任务管理局”标题。
  - 自动显示今日日期。
- [ ] **概览区域**:
  - **今日时间预算**: 输入今日总可用时间。
  - **进度条**: 动态计算 `(所有任务实际用时之和) / 总预算`，直观展示时间余额。
- [ ] **任务清单区域 (手帐核心)**:
  - 按照视觉图，从上到下垂直布局：
    1.  🔴 **最重要的任务** (1个): 醒目展示，输入框 + 预估时间 + **实际用时录入框**。
    2.  🟡 **中等任务** (3个): 列表展示。
    3.  🟢 **小型任务** (5个): 列表展示。
    4.  ⚪ **其他任务**: 允许动态添加。
- [ ] **交互逻辑**:
  - 用户完成任务后，点击复选框，并手动输入/修正“实际用时”。
  - 输入实际用时后，顶部的进度条和统计会自动更新。

## 4. 统计模块
- [ ] **实时统计**:
  - 在页面底部或侧边，根据录入的“实际用时”，自动统计“工作/个人/家庭”的时间分配比例，替代手写的麻烦。
